Create a production-quality landing page for a contemporary museum using a
DARK ROMANTIC ARCHIVAL EDITORIAL design language.

The website should feel like a museum exhibition catalogue, rare archival
publication, aged European art book, and physical cultural artifact transformed
into a digital experience — not like a conventional institutional website.

CONCEPT

Museum name: MUSEU NOCTURNE
Exhibition: "THE MEMORY OF THINGS"
Edition: EXHIBITION 034 / 2026

The central idea is:

ART + MEMORY + MATERIAL + ARCHIVE

The experience should feel mysterious, tactile, intellectual, historical and
slightly melancholic.

Avoid making it luxurious merely through empty space. The identity must come
from photography, typography, archival information, physical texture and
carefully controlled composition.

Never use pure white as the dominant text color.

Never use pure digital black as the only background.

Antique gold must occupy less than approximately 5% of the interface and should
appear only in tiny details, artwork highlights, dates, selected states or
ornaments.

The page must have visible analog materiality:

- fine film grain
- scanned-print texture
- subtle dust
- occasional scratches
- faded areas
- uneven exposure
- imperfect dark surfaces

Texture should be restrained and sophisticated. It must feel physically printed
and scanned rather than like a Photoshop noise filter.

────────────────────────────────────
TYPOGRAPHY
────────────────────────────────────

Create extreme contrast between monumental typography and microscopic metadata.

DISPLAY TYPOGRAPHY

Use a high-contrast fashion/editorial serif similar in morphology to:

- Bodoni Moda
- Instrument Serif
- Cormorant Garamond

Hero title:
clamp(64px, 11vw, 160px)

Line-height:
0.82–0.94

Tracking:
-0.03em to -0.055em

Allow typography to overlap photography.

SECONDARY CALLIGRAPHIC TYPOGRAPHY

Use an elegant handwritten/calligraphic script as a graphic intervention.

It may cross a portion of the main title like handwriting added to an archival
document.

Do not use script for normal body copy.

METADATA TYPOGRAPHY

Use a narrow neutral sans-serif for:

- exhibition numbers
- dates
- artwork IDs
- navigation
- categories
- locations
- captions

Size:
8–11px

Uppercase

Tracking:
0.08em–0.18em

The contrast between enormous serif typography and tiny metadata is essential.

────────────────────────────────────
LAYOUT SYSTEM
────────────────────────────────────

Use a 12-column editorial grid on desktop.

Outer margins:
48–72px desktop

Use repeated invisible alignment anchors, but allow controlled elements to
break the grid.

The composition should be asymmetrical.

Photography can:

- bleed outside columns
- touch viewport edges
- sit behind typography
- cross grid boundaries
- be aggressively cropped

Do NOT structure every section as centered content inside a max-width container.

Do NOT create conventional floating cards.

The page should feel composed like a sequence of editorial spreads.

Use generous dark atmospheric space, but fill some of that space with almost
invisible metadata, hairline rules, edition numbers and archival marks.

────────────────────────────────────
MOTION
────────────────────────────────────

Motion must feel slow, quiet and editorial.

Use:

600–900ms

metadata fade:
300–500ms

hairline expansion:
400–700ms

title reveal:
subtle mask/clip reveal

image hover scale:
maximum 1.02

Optional slow image drift:
1–2%

Do not use:

spring animations
bounce
glowing effects
aggressive parallax
3D card rotation
cursor trails
constant animations

Respect prefers-reduced-motion.

- aggressive artwork crops
- archive metadata
- botanical ornaments
- charcoal/ivory palette
- controlled overlaps
- grain
- edition numbers

Tablet:

Hero title mobile:
48–72px

────────────────────────────────────
ACCESSIBILITY
────────────────────────────────────

Keep important text readable despite texture.

Noise and scratches must remain behind functional text.

Use visible keyboard focus.

Interactive hit areas should target approximately 44×44px where appropriate.

Do not use low-contrast micro typography for essential navigation, prices,
opening hours, errors or accessibility information.

Use semantic HTML:

header
nav
main
section
article
figure
figcaption
footer

Provide meaningful alt text for artworks.

Decorative grain and ornaments should be ignored by assistive technology.

IMPLEMENTATION
────────────────────────────────────

Prefer:

Use raster imagery only for photography and complex physical texture.

# 06. MATERIALIDADE

O site deve possuir textura física.

Adicionar com extrema moderação:

- fine grain;
- film grain;
- paper texture;
- dust;
- scratches;
- faded blacks;
- scanner imperfections;
- uneven exposure;
- slight tonal contamination.

A textura deve parecer parte do material original.

Não aplicar um filtro uniforme de noise por cima de tudo.

Usar pelo menos três frequências:

MICRO:
fine grain

MESO:

MACRO:
exposure variation / fading / photographic imperfection

# 07. TYPOGRAPHY SYSTEM

Criar três vozes tipográficas.

## VOICE A — MONUMENTAL EDITORIAL

Usar serif de alto contraste.

Morphology:

- fashion/editorial;
- high contrast;
- elegant;
- dramatic;
- vertical;
- refined;
- slightly fragile.

Referências morfológicas:

Bodoni Moda
Instrument Serif
Cormorant Garamond
DM Serif Display

Não assumir que essas são as fontes originais.

Display:

64–160px desktop

line-height:
0.80–0.95

tracking:
-0.02em a -0.055em

Permitir títulos extremamente grandes.

Permitir que títulos:

- atravessem fotografias;
- sejam parcialmente cortados;
- saiam da coluna;
- ocupem múltiplas linhas;
- funcionem como imagem.

---

## VOICE B — CALLIGRAPHIC INTERFERENCE

Usar script/caligrafia como gesto visual.

Pode atravessar:

- título;
- fotografia;
- palavra principal;
- número de edição.

Não usar script para body copy.

O script deve parecer:

assinatura
anotação
memória
interferência humana
marca feita sobre o documento

---

## VOICE C — ARCHIVAL METADATA

Usar sans narrow / neutral grotesk.

Aplicar em:

- navigation;
- dates;
- edition;
- artwork ID;
- labels;
- categories;
- location;
- caption;
- technical information.

Tamanho:

8–11px

Uppercase

Tracking:

0.08em–0.18em

O contraste entre DISPLAY GIGANTE e METADATA MINÚSCULO é obrigatório.
